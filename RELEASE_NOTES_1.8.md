# OpenCody 1.8 – App Store release notes

You can now rename things. Press and hold a session (or right-click it on iPad) and choose Rename Session. It works the same way inside a chat, from the actions menu. Projects can get a name of their own too, with the folder path still shown underneath so you always know where you are. Reset Name brings back the folder name. Thanks for suggesting it on GitHub!

OpenCode 2.x is now the default. When you add a server, OpenCody checks which version it runs and picks the right setting for you. Servers you already added keep working exactly as before.

New for OpenCode 2.x servers:
• Pairing links: paste a pairing link from another device and the address and password are filled in for you. "Pair a Device" in the server list creates one.
• Long session lists load page by page instead of all at once.
• Retries and live cost updates show up while the agent is working.

Also new:
• Search the sessions of a project.
• Fork from Here: start a new chat from any message, and the fork opens right away.
• Pull to refresh on the project and session lists.
• Deleting a session or server, and reverting a message, now ask first.

Polish:
• Buttons, menus, toolbars and empty states use the system's own Liquid Glass components, while keeping the familiar dark look.
• The iPad layout makes better use of the space. The sidebar is visible from the start, chat tools open beside the chat instead of covering it, and there are keyboard shortcuts: Cmd+Return sends, Cmd+N starts a session, Cmd+R refreshes.
• Better VoiceOver labels, larger tap targets and chat text that follows your text size setting. Animations respect Reduce Motion.
• Subtle haptics when you send, stop, allow or deny.
• Smoother scrolling in long chats and diffs.
